## 📌 About the Project

<p align="justify">

This project presents a deep learning-based <b>hand gesture classification system</b>
using an ensemble of three pre-trained Convolutional Neural Network (CNN) models: <b>EfficientNetB7, ResNet-50, and Xception</b>.

The predictions generated by the individual models are combined using a <b>Weighted Average Ensembled Probability Pipeline</b> to improve the overall
classification performance.

</p>

The proposed ensemble model achieved an overall **98.950% accuracy**.

## 🏗️ System Architecture

### Training Phase

```text
                    TRAINING PHASE

                   Training Images
                         │
                         ▼
                 Data Pre-processing
                         │
          ┌──────────────┼──────────────┐
          │              │              │
          ▼              ▼              ▼
      ResNet-50     EfficientNetB7   Xception
          │              │              │
          ▼              ▼              ▼
       Trained        Trained        Trained
        Model          Model          Model
```

### Ensemble Phase

```text
                      TEST IMAGE
                          │
                          ▼
                  Data Pre-processing
                          │
             ┌────────────┼────────────┐
             │            │            │
             ▼            ▼            ▼
         ResNet-50   EfficientNetB7  Xception
             │            │            │
             ▼            ▼            ▼
           P₁(X)        P₂(X)        P₃(X)
             │            │            │
             └────────────┼────────────┘
                          │
                          ▼
                 Weighted Average
                          │
                          ▼
                  Final Probability
                          │
                          ▼
                 Gesture Prediction
```

## ⚖️ Weighted Average Ensemble

The final prediction is generated by combining the probability vectors produced by the three CNN models.

<p align="center">

<b>
E(X) = [w₁V₁(X) + w₂V₂(X) + w₃V₃(X)] / W
</b>

</p>
